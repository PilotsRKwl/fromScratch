FROM SCRATCH BETA

Friends Beta 10.8.1. This is not an approved RuneLite Plugin Hub release.

INSTALL
Double-click FromScratch-Beta-Setup.exe and follow the wizard.
Java is included. No terminal, developer tools or administrator account is needed.

PLAY
Open From Scratch Beta from your desktop or Start Menu.
In RuneLite, open Jagex Accounts and add your account through the official login
window. Select your character and choose Play Now. Enable From Scratch in the
plugin list and open its purple coin panel.
Official login help: https://github.com/runelite/runelite/wiki/Using-Jagex-Accounts

UPDATE
Close From Scratch Beta, then run the newer approved installer. Your challenge
is kept separately. Export Progress privately before updating.

UNINSTALL
Use Windows Settings > Apps > Installed apps > From Scratch Beta > Uninstall.
Only installed program files and shortcuts are removed. Challenge progression,
exports, RuneLite settings, account information and other plugins are retained.

DATA
Challenge: %USERPROFILE%\.runelite\plugin-data\from_scratch
RuneLite settings and account data remain in RuneLite's own user directories.
Exports remain wherever you saved them. Launcher logs are under
%LOCALAPPDATA%\FromScratchBeta\logs. Logs stay after uninstall; review/redact
them before sharing. Never send credentials, tokens or private progression.

The installer is unsigned. Windows may show a publisher/reputation warning.
Verify the source/checksum and stop if uncertain. Do not disable antivirus.
Actual launch and login require owner acceptance before distribution.
